# Supra2 100M IQ2_M: локальный чат

2026-10-18. Скачан закреплённый GGUF размером 43 942 592 байта (41,91 МиБ).
Файл и исходные HF tokenizer/template проверены по контрольным суммам.

```sh
bash tools/small_models.sh supra-iq2
# С историей собственных предыдущих ответов:
bash tools/small_models.sh supra-iq2 --history
```

В общем меню — пункт 7. `/new` очищает историю, `/quit` завершает чат.
Без `--history` запросы независимы, без системной роли Ember. На другом
компьютере после [установки зависимостей](../../small-models-playground.md)
нужно выполнить `python3 tools/small_models.py fetch supra-iq2`.

## Проверено

- Реальная генерация на Mac CPU через llama-cpp-python 0.3.16.
- Совпадение всех ID словаря HF/GGUF, ChatML без добавленного BOS, точные
  входы и независимость запросов; остановки на EOS/im_end заданы как у Q4/Q8.
- История с собственными ответами модели, сброс `/new`, `/stats`, `/quit`,
  отклонение ввода за пределами контекста без молчаливого обрезания.
- Запуск именно через новый пункт 7 shell-меню и нормальный выход.

[Отчёт CLI](report.json), [независимые ответы](supra-iq2.jsonl),
[ответы с историей](supra-iq2-history.jsonl), [источники и SHA-256](manifest.json).
Текстовые логи рядом с JSONL; в них убраны пробелы на концах строк.
В [lock-файле](../../../tools/small_models.lock.json) закреплены ревизии
GGUF и исходного токенизатора.

Внутри GGUF 100 684 032 значения весов: 49 тензоров F32, 1 Q5_K,
59 IQ2_S и 25 IQ3_S. IQ2_M обозначает смешанный профиль, не ровно два бита
на каждый параметр. Контекст настроен на 2048, автор исходной Supra сообщает
об обучении с длиной 1024.

## Ограничения качества

PASS означает корректную работу программы, а не правильные ответы.
В коротком прогоне модель присвоила себе имя Sofia; на вопрос о цвете травы
начала с «Kidney, grass, grass!» и не дала корректного простого ответа.
Этого недостаточно для количественного сравнения качества с Q4/Q8.
Параметры и полные ответы сохранены в JSONL.

Это запуск на компьютере. Прошивка и её модель не менялись.
