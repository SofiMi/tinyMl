## Поиграть на этом Mac

Из корня репозитория, в уже установленном окружении:

```sh
/Users/simasl/.cache/tinyml-eval-venv/bin/python tools/gpt2_small.py chat
```

По последнему запросу пользователя **каждый ввод независим**: в модель идёт
только введённая строка, без предыдущих вопросов/ответов, роли Ember,
`User:`/`Ember:` и системного сообщения. Веса те же; изменена оболочка запуска.
Пишите начало английского текста после `You:`, продолжение появится после
`GPT-2:`. Лучше `A baby dragon met a little boy named Ramil. Together, they`,
чем инструкция написать рассказ: базовая GPT-2 обучена продолжать текст.

`/quit` выходит; `/context` показывает **только последний введённый текст**,
который хранится для просмотра и не используется в следующей генерации;
`/stats` показывает `history=0 role_prompt=0` и лимит. `/new` очищает просмотр,
но каждый ввод и без него начинается с пустой истории. RNG задаётся один раз
на запуск, чтобы не повторять последовательность случайных чисел на каждом вводе.
Старый уже работающий процесс нужно закрыть и запустить команду заново.
Для сохранения точных входов/выходов добавьте `--trace build/gpt2-small/play.jsonl`
(новый файл). [Проверка независимого ввода](stateless-check.txt).

Обычное продолжение текста:

```sh
/Users/simasl/.cache/tinyml-eval-venv/bin/python tools/gpt2_small.py complete \
  --prompt "A baby dragon met a little boy named Ramil. Together, they" \
  --max-tokens 128 --temperature 0.7
```

Для нового компьютера нужны `torch==2.14.1`, `transformers==5.20.1` в отдельном
Python-окружении (проверено с Python 3.10). После проверки свободного диска:
`python tools/gpt2_small.py fetch`, затем `python tools/gpt2_small.py chat`.
Загрузка занимает около 550 МБ без зависимостей. `fetch` проверяет ревизию,
размеры и хеши; последующие команды работают офлайн и повторно проверяют файлы.
Загрузка `.bin` использует `weights_only=True`, удалённый код отключён.

## Качество и повторение

124 439 808 обучаемых параметров, 12 слоёв, hidden 768, словарь 50 257,
1024 позиции. Локальный CPU FP32, eager attention, KV-cache включён,
2 потока; torch 2.14.1, transformers 5.20.1. Mac не является замером ESP.

[Отчёт после исправления RNG](report.json): четыре отдельных запроса и один
семиходовый разговор при T=0 и T=0.7; максимум 64 новых токена на ответ.
Sampling: top_p=0.9, top_k=50, seed=42 один раз на разговор. Отдельные запросы
начинаются с seed=42 каждый. История в этой оценке не обрезалась; во всех
разговорах лимит не достигнут. Режим `eval` сохраняет контекстный сценарий для
повторения диагностики; текущий интерактивный `chat` работает без него.
В контекстной оценке роль Ember задана обычным текстом, ответы обрезаются
до следующего `User:` или `Ember:` на новой строке, сырые продолжения сохранены.

- В greedy-разговоре исправление имени на Anna сохраняется, но собственное
  имя модель путает с именем пользователя. На цвет травы отвечает `Grass.`.
- При T=0.7 имя и роль теряются: модель объявляет себя владельцем магазина,
  затем пишет про город Ember. На цвет травы перечисляет несколько цветов.
- Неизвестные предпочтения пользователя выдумываются.
- Продолжение истории повторяется; правильное начало `Paris` при sampling
  продолжается ошибочными фактами.

Это небольшой диагностический набор, а не независимая оценка accuracy.
Базовая GPT-2 в таком виде не подходит как готовый разговорный Ember.

Пользовательский цикл `hello → i a ms sofia → what do you do? → ...`
воспроизведён: шесть ответов `I'm Ember!`. [Разбор](context-diagnosis.json)
сохраняет точные промпты и полные ответы для двух вариантов. Все реплики
попадали в модель; вход рос с 27 до 119 токенов. Причина закрепления именно
этого цикла — сброс `torch.manual_seed(42)` перед каждым ответом. После перехода
на один seed в начале разговора шесть ответов различаются, но остаются слабыми
по смыслу. Это исправление sampling, не улучшение обученных весов.

[Первоначальная оценка](initial-reset-seed.json) сохраняется отдельно: в ней
RNG сбрасывался на каждом ходе. Не сравнивать её sampling-разговоры как будто
они получены окончательным скриптом. Проверка прежнего CLI до исправления
падала на трёх одинаковых ответах, после исправления проходила и проверяла
сохранение обеих сторон разговора. [Её результат](chat-regression.txt) сохранён
как исторический; после запроса убрать контекст проверка заменена на прямое
сравнение переданных модели строк с текущими вводами пользователя:

```sh
python tools/check_gpt2_chat.py
python tools/gpt2_small.py eval --output build/gpt2-small/new-report.json
```

Независимый ввод и исправление RNG не гарантируют, что GPT-2 никогда не
будет повторяться внутри одного продолжения.

## Память

Только веса GPT-2: 497 759 232 байта FP32, 62 219 904 байта при идеальной
упаковке в 4 бита, без масштабов квантования. FP16 KV для этой архитектуры
занял бы 9 МиБ на 256 позиций или 36 МиБ на 1024 позиции; в текущем CPU FP32
он вдвое больше. Поэтому этот запуск предназначен для компьютера.
