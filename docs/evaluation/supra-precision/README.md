# Supra2 и Stentor: локальное сравнение Q4/Q8

2026-10-18, Mac, CPU, llama-cpp-python 0.3.16. Скачаны и запущены Supra2-100M
Q4_K_M / Q8_0 и Stentor-30M Q8_0; Stentor Q4 был скачан ранее. Размеры и
контрольные суммы проверены. Обучение не проводилось, прошивка не менялась.

## Как повторить

```sh
bash tools/small_models.sh supra
bash tools/small_models.sh supra-q8
bash tools/small_models.sh stentor-q8
```

По умолчанию запросы независимы, без системной роли Ember. `--history` включает
историю, `/new` сбрасывает её, `/quit` завершает чат. [Установка и параметры](../../small-models-playground.md).

Сравнение записано скриптом `tools/compare_small_models.py`: три независимых
запроса и один разговор из шести запросов с собственными предыдущими ответами.
Greedy (`temperature=0`), два CPU-потока, repeat_penalty=1.1, top_k=40,
top_p=0.9; последние два ограничения не выбирают случайный токен при greedy.
Лимит ответа — 64 токена в независимых запросах и 32 в разговоре. Ответ,
обрезанный по лимиту, нельзя считать полным рассказом. Это общие настройки
сравнения, а не точное воспроизведение рекомендаций авторов по sampling.

Входной формат взят из исходного HF chat_template, все ID словаря сверены
с GGUF. Supra получает ChatML без добавленного BOS и останавливается на EOS
или im_end. Максимум входа вместе с сгенерированным ответом в этом опыте —
294 токена: результаты не затрагивают спорную экстраполяцию Supra выше
обучающей длины 1024. В config указано 2048.

## Что получилось

| Вариант | Файл весов, байт | Наблюдения в этих запросах |
| --- | ---: | --- |
| Supra Q4 | 67 102 400 | Присваивает себе имя Sofia, затем Anna; на смену темы продолжает представляться |
| Supra Q8 | 108 208 832 | Аналогичная путаница ролей; зацикливается на собственной выдуманной биографии |
| Stentor Q4 | 20 913 792 | Повторяет вопросы и инструкции, связного разговора не получилось |
| Stentor Q8 | 33 110 656 | Повторы сохраняются; увеличение точности не исправило проверенные задания |

На «What color is grass? Answer in one short sentence.» обе версии Supra
ответили одинаково: «Grass is a color that is often associated with the color
of the grass.» В рассказе Supra Q4 сделала Ramil драконом вместо мальчика.
Supra Q8 начала с мальчика, но в первых 64 токенах дракон не появился.
В разговоре Q4 выдумала любимую еду пользователя, Q8 снова представилась.

Это **36 ответов, не независимый benchmark и не доказательство превосходства
одной архитектуры**. Проверки показывают, что переход Q4 → Q8 не устранил
замеченные здесь ошибки. Они не устанавливают качество неквантованной основы:
FP32/BF16 этих двух моделей в этом опыте не проверялись. Stentor Q8 и Supra Q4
различаются и обучением, и архитектурой, и размером файла; сравнение не имеет
равного бюджета памяти. Повышение битности уменьшает ошибку хранения весов,
но само по себе не добавляет знаний или навыков диалога.

- [Среда, версии и контрольные суммы](receipt.json).
- [Проверки реальных CLI](cli/report.json): все шесть вариантов, управление
  историей для пяти диалоговых вариантов, сброс, отклонение слишком длинного
  ввода. Тексты и JSONL рядом с отчётом. PASS относится к работе программы,
  а не к правильности ответов модели.

В JSONL сохранены исходные ответы, точные входы и ID токенов. В текстовых
CLI-логах убраны только пробелы на концах строк. Время записано для диагностики
локальных запусков; сравнение и CLI-проверки выполнялись параллельно, поэтому
эти значения не являются честным скоростным benchmark, тем более для ESP.
