# Локальный учитель для английского дракона

Учитель работает на компьютере и создаёт примеры диалогов для обучения
маленькой модели. На ESP32 загружается только маленькая модель после
отдельной проверки качества, памяти и скорости. Квантование учителя само по
себе не превращает его в модель, помещающуюся на ESP32.

Первый кандидат в учителя — Qwen3.5-9B через Ollama. Доступный Mac:
Apple M3 Pro, 36 GiB общей памяти, GPU Metal. Модель занимает несколько
гигабайт на диске; оперативной памяти нужно больше размера весов.
Контекст ограничен 2048 токенами. API-ключ и облачная подписка не нужны.

## Запуск на Mac

```sh
brew install ollama
OLLAMA_HOST=127.0.0.1:11434 OLLAMA_CONTEXT_LENGTH=2048 OLLAMA_NO_CLOUD=1 ollama serve
```

Оставьте сервер работающим. В другом терминале:

```sh
ollama pull qwen3.5:9b
cd /path/to/tinyMl
python3 tools/dragon_teacher.py chat
```

`/new` очищает историю, `/quit` завершает чат. Ember — временное имя
персонажа для эксперимента, заданное в `PERSONA` в скрипте. Последние шесть
пар реплик передаются вместе с характером персонажа; это не долговременная память.
Интернет нужен для установки и загрузки весов, последующие ответы вычисляются
на Mac. Сервер слушает только `127.0.0.1`; облачные функции отключены.

## Проверка перед созданием обучающих примеров

```sh
python3 tools/dragon_teacher.py eval
ollama ps
```

Результаты: `build/dragon/teacher-eval.json`. Скрипт сохраняет digest модели,
настройки, все ответы, причины остановки и время. Проверяются десять сценариев:
роль, имена, исправление имени, память о подарке и несколько открытых вопросов.
Совпадение ключевых слов — только быстрая проверка; ответы нужно прочитать.
Например, наличие «Maya» не исключает, что ответ также ошибочно утверждает «Lily».
Остановка по лимиту токенов требует отдельного внимания.

Эти сценарии отложены для оценки и не должны становиться обучающими примерами.
Сначала проверяем учителя, затем создаём отдельные разнообразные диалоги,
отбрасываем противоречия и обучаем ученика на ответах учителя. Это дистилляция
через синтетические тексты, без копирования внутренних весов или логитов.
Качество ученика измеряется отдельно: хороший учитель не гарантирует,
что очень маленькая модель освоит все его способности.

Состояние прошивки ESP32 эта установка не меняет.

## Первый замер, 17 октября 2026

Ollama 0.40.5, модель `qwen3.5:9b`, digest начинается с `d63f830f28d5`;
фактически выбран backend MLX. `ollama ps`: 9,4 GB, 100% GPU, контекст 2048.
Скачанный пакет занял около 7,6 GB; после установки на этом Mac осталось
около 4,7 GiB свободного места. Не скачивайте параллельно несколько больших
учителей без проверки свободного места.

[Полный протокол](evaluation/dragon-teacher-qwen35-9b.json): 10 сценариев,
15 ответов, все завершены естественно, все укладываются в 30 слов. В восьми
сценариях с ключевыми словами ожидаемые слова присутствовали. При чтении
ответов роль и имена соблюдены, неизвестное имя не выдумано, цвет подарка
сохранён. Ответ после исправления имени корректно содержит Maya, но зря
повторно спрашивает о предпочтении. Часто повторяются камешки и пещера —
для будущих данных потребуется больше разнообразия.

Суммарно около 24,1 секунды на 15 запросов; скорость генерации по сумме
`eval_count / eval_duration` — около 24,6 токена/с. Это один небольшой
прогон, а не универсальный benchmark. Обучение ученика ещё не запускалось.
